# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the label strings used in HireJourney Jira ticket drafts.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| -------------------------- | -------------------- | ------- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and suitable for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a canonical triage role, use the corresponding label string from this table.

Agents may recommend these labels in ticket drafts but must not apply them in Jira.
